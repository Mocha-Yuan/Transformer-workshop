# Transformer-workshop
帮助英语专业学生转行 AI 第一期：用一款中文像素风互动学习游戏，把 Transformer、注意力机制和大模型基础讲得更直观、更接近翻译学习者的经验。Phase 1 of helping English majors transition into AI: a Chinese pixel-art interactive learning game that makes Transformers, attention mechanisms, and LLM fundamentals easier to understand through translation-based analogies.
